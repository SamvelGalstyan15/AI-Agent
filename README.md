# 🤖 AI Agent: Автоматическая классификация и семантический маппинг номенклатуры

Промышленный ИИ-агент на базе локальной LLM (**Qwen 2.5**) и векторного поиска (**LaBSE + ChromaDB**) для автоматизации процесса разбора накладных поставщиков и их бесшовной интеграции со складским учетом системы **iiko**.

Сервис работает полностью локально, гарантирует конфиденциальность коммерческих данных и разворачивается в виде production-ready бэкенда на фреймворке **FastAPI**.

---

## 💡 Основной функционал и архитектурный паттерн

Проект реализует продвинутую гибридную логику классификации данных на стыке NLP и классического ML:

1. **Семантический маппинг (Vector Search):** Входящая "грязная" строка из накладной векторизуется мультиязычной моделью `LaBSE` и сравнивается с существующей базой товаров в `ChromaDB`. Система рассчитывает коэффициент уверенности (`distance score`). Если товар найден с высокой точностью, агент мгновенно производит стыковку.
2. **Локальный LLM-Агент (Structured Extraction):** Если точного совпадения нет, позиция передается локальной языковой модели `Qwen 2.5`. Агент выполняет zero-shot извлечение характеристик (чистое имя, бренд, объем/вес, единицы измерения, процент жирности) и автоматически подбирает наиболее логичную категорию номенклатуры (включая поддержку локализованных групп, например, на армянском языке: *«Ջրեղեն»*, *«Կաթնամթերք»*).
3. **Structured JSON Output:** На выходе агент гарантированно отдает строго валидный JSON-объект через Pydantic-схему, полностью готовый к отправке в REST API iiko.

## 🛠 Стек технологий

* **LLM Core:** Hugging Face Transformers, Qwen 2.5 (Instruct)
* **Vector DB & Embeddings:** ChromaDB (Persistent Storage), SentenceTransformers (LaBSE)
* **Backend API:** FastAPI, Uvicorn, Pydantic
* **Data Science:** Python, Pandas, PyTorch
* **Разработка и логи:** Изоляция памяти (`gc`, `torch.cuda.empty_cache`), фильтрация предупреждений.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
Склонируйте репозиторий и установите пакеты из файла манифеста:
```bash
pip install -r requirements.txt
```

### 2. Запуск проекта
1. Откройте интерактивный ноутбук **`Agent.ipynb`** в вашей среде разработки (Jupyter Lab, VS Code или Google Colab).
2. Запустите все ячейки по порядку (команда **Run All**).
3. Ноутбук автоматически инициализирует локальную векторную базу данных `ChromaDB`, скачает веса моделей и запустит тестирование локального LLM-агента для разбора номенклатуры iiko.
